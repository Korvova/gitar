# Ремни TPU — «Т. Трос реабилитация» (карта папки для продолжения работы)

Вики: «Т. Трос реабилитация» (`wiki/t-tros-reabilitacija.md`, строки 21.1–21.24), хроника — `wiki/hronika.md`.
Python для деталей: `2-0/.venv-b123d` (build123d), запускать с `PYTHONIOENCODING=utf-8`. Сцены Blender 5.1: `blender -b -P <скрипт>.py`.
Столы печати собирает `2-0/make_3mf.py` (`python make_3mf.py <номер>`), раскладка сеткой (`grid(...)`, флаг `"grid"`).

## Где мы сейчас (28.11.2026)

**Направление — «гусеница» (21.23), печатается стенд на один мотор (21.24).**

- Плоская петля (v8–v13: ремни лежат горизонтально, ведущий Ø5 в центре петли) на стенде 21.22 **проскальзывала**: ведущий цепляет ремень ~1 зубом.
- Владелец предложил: ленты — **вертикальные петли** поперёк грифа; моторы GB1806 **лёжа, за зоной пальцев** (по два с каждого конца, валы вдоль грифа);
  на концах петли ролики **Ø10, 12 зубьев** — обхват ~180°, ~6 зубьев в зацеплении. Зона пальцев 24.3 мм с плитой грифа (v13 — 29.4).
- **Крышка-клавиша** над лентой: закрывает ремень, ведёт тележку (стойка в прорези, лапки под крышкой) и жмёт кнопку. Качается на гибком
  язычке вдоль ДЛИННОГО края (стенка между лентами), кнопка Ø6 в стакане-«вазе» — под серединой другого края: место тележки на нажатие не влияет.
- **Крепление тележки к ремню — два ушка-«пилы»** на спинке ремня (по 3 мм вдоль ремня, грань к зубу вертикальная, наружу скат), зуб тележки между ними.
  Толкающее ушко всегда на прямом участке, наружное гнётся на ролике. Одно ушко без пил не может быть длиннее 2 мм (прямой участок − ход = 44 − 42).
- **Вибрация:** сам гимбал через ремень; в запасе — связь от неподвижного стакана мотора к стенке (v6) или вибромотор-таблетка Ø8 × 2.5 на крышке.
- ⚠️ У лежачего GB1806 перед стаканом **крутится весь корпус** — держать мотор только за стакан (на стенде — 6 × М2 на Ø18 через кронштейн).

**Следующий шаг:** владелец печатает столы 132 (PLA) и 133 (TPU), собирает стенд, проверяет ход, зацеп, кнопку, вибрацию. По итогам — блок на 4 ленты.

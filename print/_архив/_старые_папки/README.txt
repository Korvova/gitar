ПОРЯДОК ПАПОК ПЕЧАТИ
====================
Печатай папки по номерам: 1 -> 2 -> 3 -> 4.
Новые правки деталей будут появляться в НОВЫХ папках (5, 6, ...) — 
в старые папки ничего не дописывается, что напечатано — то напечатано.
0_стенд_архив — детали тестового стенда (уже напечатаны, хранить как запас).
_свежее_из_скрипта — сырой вывод скриптов, НЕ печатать отсюда.
